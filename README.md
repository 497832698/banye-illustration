# banye-illustration · 般叶专属配图 Skill

> 单一角色怪诞手绘配图 Skill —— **只能生成「般叶（Banye）」形象**，由文章正文一键产出插画。

---

## 1. 项目主要解决什么问题

- **固定角色、不侵权**：从 `gimi-illustration` 派生并彻底移除原版 Gimi 角色、none 无角色模式与自定义 IP 录入流程，锁定为原创角色「般叶（Banye）」，避免换 IP 带来的版权风险。
- **角色一致性**：通过身份锚点（银白短发 / 左 1 右 4 不对称银环 / 银项链 / 黑眼线 / 无眼镜 / Q 版大头）最高优先级锁定 + 双参考图协议，确保不同提示词、不同穿搭下生成的图都「认得出是同一个人」。
- **一键配图**：输入中文文章正文，自动完成「消化内容 → 出构图策略 → 组装 prompt（含参考图）→ 调用生图 → QA 质检」全流程，无需手动写提示词。

## 2. 主要功能

- **单一角色强制锁定**：本 Skill 生成的每张图主角永远是般叶，不调用任何其他角色 IP。
- **衣橱库换装（按关键词自动路由）**：内置 9 套服装（白西装 / 短袖 / 背心 / 黑西装 / 礼服 / 牛仔 / 流行 / 韩系 / 杀马特）。用户说「般叶穿牛仔」「韩系」即自动切换对应服装；**仅衣服变化，身份锚点永远不变**。当前 8/9 套参考图已入库（流行/潮流 street 暂未补）。
- **双参考图协议**：每次生图自动附上「设定图 `reference-character.png` + 怪诞手绘校准图 `banye-sample.png`」，换装时再补对应服装参考图，把「换装不认错人」的可靠性拉满。
- **怪诞手绘风格（quirky-sketch）**：固定单风格，含色纪律与 QA 规则，保证成片调性统一。
- **多比例输出**：默认 16:9，可指定任意比例（如 3:4 竖版、1:1 方图）；可选张数与顶部手写标题。
- **序列图能力**：支持沿故事动线（指路 / 按按钮 / 托腮思考 / 拉物件）生成步骤化配图，般叶站位与引导动作可控。
- **质检（QA）**：内置走形信号清单（锚点走形 / 配色走形 / 流程缺失），不通过自动重试，最多 2 次。

## 3. 安装方式

本 Skill 运行在 **WorkBuddy** 中（智能体读取 `SKILL.md` 并调用平台内置生图工具）。两种安装方式：

**方式 A · 从 GitHub 克隆（推荐）**

```bash
# 放入用户级 skills 目录（对所有项目生效）
git clone https://github.com/497832698/banye-illustration.git \
  ~/.workbuddy/skills/banye-illustration

# 或放入项目级 skills 目录（仅当前项目生效）
# git clone https://github.com/497832698/banye-illustration.git \
#   <你的项目>/.workbuddy/skills/banye-illustration
```

克隆后重启/刷新 WorkBuddy 对话，Skill 即自动发现，无需额外配置。

**方式 B · 手动放置**

下载仓库 ZIP 解压，把整个 `banye-illustration/` 文件夹移到 `~/.workbuddy/skills/` 下即可。

> 前置条件：WorkBuddy 已就绪，且当前平台支持生图（ImageGen 等）。Skill 本身只负责策略、prompt 组装与参考图附件，最终生图由平台生图工具执行。

## 4. 使用方法

在 WorkBuddy 对话里直接发触发词 + 你的文章正文：

```
配图

[粘贴你的文章正文]
```

- **触发词**：`配图` / `给我般叶配图` / `帮我配图` / `illustration`
- **无需指定角色**：生出来的图主角固定为般叶。
- **可带选项**（自然语言即可）：
  - 比例：`3:4 竖版` / `1:1 方图`（默认 16:9）
  - 张数：`配 3 张`
  - 标题：`顶部加手写标题「xxx」`
  - 换装：`般叶穿牛仔` / `韩系` / `礼服` ……

**最简示例对话：**

```
用户：给我般叶配图，3:4 竖版，般叶穿韩系

[一段中文产品介绍正文]

助手：→ 自动出构图策略 → 组装含般叶设定图+校准图+韩系参考图的 prompt → 调用生图 → QA → 交付 3:4 韩系般叶插画
```

## 5. 输入 / 输出示例

**输入（用户消息）**

```
配图，16:9

般叶是一位喜欢极简设计的产品设计师。今天他接到一个新任务：
为一款蓝牙耳机画一张怪诞手绘风格的功能介绍图，要突出「轻盈」和「佩戴舒适」。
```

**输出**

- 一张 16:9 怪诞手绘风格插画，主角固定为般叶（银白短发、左 1 右 4 银环、银项链、白西装默认款、Q 版大头、痞帅表情）。
- 画面按「轻盈 / 佩戴舒适」生成对应构图（如般叶托腮思考或手持耳机比划），不出现其他角色。
- 同时落盘 `outputs/{日期}-{slug}/shot-config.md`（配图策略与插入位置），便于复盘。

**换装示例**

| 用户说 | 生成结果 |
|--------|---------|
| `配图，般叶穿礼服` | 般叶身着黑色丝绒礼服 + 领结，锚点不变 |
| `配图，般叶牛仔风` | 般叶身着做旧牛仔外套 + 牛仔裤，锚点不变 |
| `配图`（不指定） | 般叶默认白西装套装 |

> 所有换装均保证：发型、耳环数量与位置、项链、脸型、比例、眼线完全一致，只换衣服。
