# prompts-zh.txt — 中文说明 + 服装关键词映射
#
# 本文件教你「用中文工具（通义万相 / 豆包 / 即梦 / ChatGPT 中文）」时怎么操作。
# 英文完整提示词在 prompts-en.txt（更稳定，优先用）。

================================================================
一、操作步骤（中文工具通用）
================================================================
1. 上传 3 张参考图：
   - 设定图   assets/ip/banye/reference-character.png   （管「是谁」）
   - 校准图   assets/ip/banye/examples/quirky-sketch/banye-sample.png  （管「画成什么手绘质感」）
   - 服装图   assets/ip/banye/outfits/{id}/reference.png  （管「穿哪套」）
2. 把 prompts-en.txt 里对应那套的英文 prompt 整段粘贴（英文比中文稳定）。
   若执意用中文，可在图后直接写：「请按上面三张参考图生成般叶，穿【对应服装】，怪诞手绘风格，白底留白」。
3. 发送，等出图；不满意就说「保持参考图里的般叶形象，把 XX 改成 XX」。

================================================================
二、8 套服装 → 关键词 / 中文描述
================================================================
id=white_suit   白西装（默认）     关键词：白西装 / 西装
id=short_sleeve 短袖             关键词：短袖 / 半袖 / T恤
id=vest         背心             关键词：背心 / 无袖 / 坎肩
id=black_suit   黑西装           关键词：黑西装 / 暗黑西装
id=tuxedo       礼服             关键词：礼服 / 正装 / 燕尾服
id=denim        牛仔             关键词：牛仔 / 丹宁
id=korean       韩系             关键词：韩系 / 清爽
id=visual       杀马特/视觉系    关键词：杀马特 / 视觉系

================================================================
三、绝对不能变的锚点（无论换什么衣服）
================================================================
- 银白普通短发（不是长发、不是金发）
- 左耳 1 枚银环 + 右耳 4 枚银环（不对称是核心识别点）
- 银色链条项链
- 不戴眼镜
- 黑色上挑眼线，痞帅冷感
- Q 版大头，头身比约 1:1.3

如果出图把耳环画对称了、头发变长变金、或戴了眼镜，说明没吃准参考图——
重传 3 张图 + 用 prompts-en.txt 英文 prompt 重试。

================================================================
四、风格约定（让图更「怪诞手绘」）
================================================================
- 白底、至少 25% 留白、不铺满
- 线稿为主，软蓝点缀、软橙最多 2 处
- 具体物件 + 故事动线（箭头/路径）
- 不要：可爱卡通风、PPT 信息图、渐变、3D 渲染、彩色标签底
